# skills

Study-specific skills live in this project directory, kept flat: one directory per skill, no category hierarchy. Each skill directory contains a `SKILL.md` (with `name` and `description` frontmatter) plus any supporting files. Skills operate on artifacts under this Study root.

- `generate-textbook/` – extract intent from an arbitrary curriculum source and organize it into a subject-neutral textbook format.
- `generate-mock-exam/` – create original uniform mock exams from a generated textbook and its source guide, with lookup-based drift checks.
