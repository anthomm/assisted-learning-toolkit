# AZ-900: Microsoft Azure Fundamentals

An original study book for the AZ-900 exam. Content is written in the author's own words from official Microsoft Learn documentation and organized around the intent of the [Microsoft AZ-900 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900) (skills measured as of July 20, 2026). It is an independent study aid, not Microsoft material.

## Scope and weights

| Chapter | Exam weight |
|---|---:|
| 1. Cloud concepts | 25–30% |
| 2. Azure architecture and services | 35–40% |
| 3. Azure management and governance | 30–35% |

Source record and extraction notes: [CURRICULUM.md](CURRICULUM.md). Outcome-to-section-to-question map: [coverage.md](coverage.md). The map supports review; it is not a guarantee of exhaustive coverage.

## How to use this book

Read each topic in order or jump to a gap via the coverage map. Every topic follows the same pattern: learning intent, core concepts, distinctions and limits, a worked scenario, hands-on steps where relevant, exam application, and self-check questions. Then take the matching 100-question mock exam (`mock_exams/az_900/`) and revisit weak topics, using the `objective:` tags to find them.

Azure changes often. Items marked **Verify** are version-sensitive; check the linked Microsoft documentation before relying on them. The guide scopes the exam; it is not a complete course, and enrichment beyond it is noted in the text.
